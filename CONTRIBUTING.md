# Contributing

This repository is an independent DeepSeek Harness plugin, not part of the official monorepo.

1. Open an issue before changing a mutation, approval, or restore behavior.
2. Keep each pull request focused on one Git workflow.
3. Update tools, tests, skill instructions, and bilingual documentation together.
4. Run `pnpm run check` and report only the commands actually run.

Never add credentials, signed Git material, local restore-point state, generated tarballs, or test repositories to a contribution.
